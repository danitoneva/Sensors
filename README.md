# Sensors Simulation and Validation System (Python OOP)

## Description 
The following sensors have been simulated in this module:
 * inductive sensor
 * photoelectric sensor 
 * pressure sensor

Validation has been performed - checking the values against minimum/maximum thresholds or statistical rules.
After that, unit tests were done with all corner cases. The sensors were tested using pytest.

## Geting started 

### Instalation

## Tests 
To run the pytests in the test directory run the following command:
    python -m pytest /path to the file/
